# 🌌 Interactive 3D Solar System

An interactive 3D Solar System simulation developed as a **Computer Graphics project** using **C++, OpenGL, GLU, and FreeGLUT**.

The project visualizes the Sun, all eight planets, planetary orbits, moons, asteroid belt, stars, lighting, camera movement, animation, and interactive controls.

## 🚀 Features

- ☀️ 3D Sun with glow effect
- 🪐 All 8 planets
- 🔄 Planet rotation
- 🌍 Planet revolution around the Sun
- 🌙 Multiple planetary moons
- 💍 Saturn's rings
- ☄️ Asteroid belt
- ⭐ 1000-star background
- 🌀 Planetary orbit visualization
- 💡 OpenGL lighting
- 🌎 Earth surface details
- 🌐 Earth atmosphere effect
- 🎥 Interactive 3D camera
- 🔍 Mouse-wheel zoom
- 🎯 Planet selection
- 📋 Planet information panel
- ⏯️ Pause and resume animation
- ⚡ Animation speed control
- 👁️ Toggle stars, orbits, labels, asteroids, moons, and atmosphere
- 🔄 Reset simulation

## 🎮 Controls

| Key | Function |
|---|---|
| `1` | Select Mercury |
| `2` | Select Venus |
| `3` | Select Earth |
| `4` | Select Mars |
| `5` | Select Jupiter |
| `6` | Select Saturn |
| `7` | Select Uranus |
| `8` | Select Neptune |
| `SPACE` | Pause / Resume |
| `+` / `=` | Increase animation speed |
| `-` / `_` | Decrease animation speed |
| `A` | Toggle Asteroids |
| `O` | Toggle Orbits |
| `S` | Toggle Stars |
| `L` | Toggle Planet Labels |
| `M` | Toggle Moons |
| `G` | Toggle Earth Atmosphere |
| `R` | Reset simulation |
| `Arrow Keys` | Move camera |
| `Mouse Wheel` | Zoom in / out |
| `ESC` | Exit |
